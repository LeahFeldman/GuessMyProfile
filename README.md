# Guess My Profile
### An interactice website to make profile predictions.

> ***Author: Leah Feldman***

>Based on an inputted first name, this website will guess:
>* Gender
>* Age
>* Nationality 

***How it works:***
*Our website is an interactive user interface which makes API calls to various APIs.*

**We find the info for you, so you don't have to sweat the small stuff!**
